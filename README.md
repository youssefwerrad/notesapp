# Notes App

A simple React notes application built with Vite. Create, view, and delete notes with optional image attachments — no backend or cloud services required.

## Features

- Create notes with a name, description, and optional image
- View all notes in a responsive grid layout
- Delete notes
- Images are previewed locally using object URLs

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to view the app.

## Tech Stack

- [React 19](https://react.dev/)
- [Vite](https://vitejs.dev/)

> AWS Amplify and all cloud dependencies have been removed. All data is stored in local component state.
